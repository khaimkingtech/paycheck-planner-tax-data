# Paycheck Planner tax data

Public tax figures (federal brackets, FICA, contribution limits, credits and all 50 states + DC) used by the Paycheck Planner app.
The app checks `tax-data.json` here and switches to it when its `year`/`updated` is newer than the copy built into the app.

Refreshed each January. Contains no personal data.

Also hosts the Payperity [support page](index.html) and [privacy policy](privacy.html) via GitHub Pages.
